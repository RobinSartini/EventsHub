title: API
description: Les endpoints exposés par apps/server.
---

La source de vérité est le contrat OpenAPI [`contrat/openapi.yaml`](https://github.com/RobinSartini/EventsHub/blob/main/contrat/openapi.yaml). Il se met à jour dans la même PR que le code.

L'authentification passe par le cookie de session posé par Better Auth. Les routes admin répondent `401` sans session et `403` sans le rôle `admin`.

| Méthode  | Route                     | Accès    | Rôle                               |
| -------- | ------------------------- | -------- | ---------------------------------- |
| `GET`    | `/events`                 | public   | Liste des événements publiés       |
| `POST`   | `/api/auth/sign-up/email` | public   | Inscription                        |
| `POST`   | `/api/auth/sign-in/email` | public   | Connexion                          |
| `POST`   | `/api/auth/sign-out`      | connecté | Déconnexion                        |
| `GET`    | `/api/auth/get-session`   | connecté | Session courante                   |
| `POST`   | `/api/auth/refresh`       | connecté | Obtenir un access token            |
| `GET`    | `/api/auth/jwks`          | public   | Clés publiques des access tokens   |
| `GET`    | `/users`                  | admin    | Liste des utilisateurs             |
| `PATCH`  | `/users/{id}`             | admin    | Modifier le rôle ou le statut      |
| `GET`    | `/admin/events`           | admin    | Liste de tous les événements       |
| `PATCH`  | `/admin/events/{id}`      | admin    | Modifier n'importe quel événement  |
| `DELETE` | `/admin/events/{id}`      | admin    | Supprimer n'importe quel événement |

Pour explorer l'API sans lancer le serveur, démarrez un mock à partir du contrat :

```bash
npx @stoplight/prism-cli mock contrat/openapi.yaml -p 4010
```
