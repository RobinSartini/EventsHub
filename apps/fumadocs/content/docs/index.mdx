EventsHub est un monorepo qui regroupe le front web, l'API, l'app iOS et la base de données.

## Architecture

| Dossier         | Rôle                                          |
| --------------- | --------------------------------------------- |
| `apps/web`      | Front web (React Router, Tailwind, shadcn/ui) |
| `apps/server`   | API REST (Hono, Better Auth)                  |
| `apps/native`   | App iOS (SwiftUI)                             |
| `apps/fumadocs` | Cette documentation                           |
| `packages/db`   | Schéma Prisma et accès PostgreSQL             |
| `packages/auth` | Configuration Better Auth                     |
| `packages/env`  | Validation des variables d'environnement      |
| `contrat`       | Contrat d'API OpenAPI                         |
